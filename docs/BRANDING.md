# Brand decision

* **Name:** إنصاتو — **Insato** (approved by the owner on 2026-11-19).
* **Meaning:** from إنصات — full, respectful, attentive listening: it listens to every
  language and every speaker, then writes the minutes.
* **Tagline:** يُنصت لكل صوت، ويكتب كل قرار · Insato — AI Meeting Minutes.
* **History:** working name Katib/كاتب dropped (collision with the "Kateb" dictation
  app by RDI); Raqim/رقيم dropped (used by Saudi AI/software companies — Rqeem Smart
  Solutions, Lean's Raqeem HIS — and a "Raqim AI" app on Google Play).
* **Screening (web search only, 2026-11-19):** 30 coined names generated, 10
  shortlisted and screened; Insato was the only low-risk candidate. No exact app,
  company, domain page or trademark found. Nearest: asato.ai (enterprise AI),
  MunsitAI (UAE Arabic transcription, same root ن-ص-ت, different name).
* **Still required before launch:** formal trademark search in classes 9 and 42 —
  Saudi SAIP (https://ipsearch.saip.gov.sa/), UAE MoE
  (https://www.moec.gov.ae/en/trademark-search), Egypt ITDA (https://itda.gov.eg/),
  WIPO (https://branddb.wipo.int/); WHOIS for insato.ai / insato.app / insato.com;
  native-speaker check of how إنصاتو reads in Gulf/Egyptian Arabic.
* **Rename plan (after the v1 build finishes):** user-visible app name on
  Android/iOS/Windows, window title, strings, README and docs → Insato/إنصاتو;
  application id / bundle id → `app.insato.insato`; Dart package `katib` → `insato`.
  The owner can rename the GitHub repository (Settings → Rename → `insato`).
