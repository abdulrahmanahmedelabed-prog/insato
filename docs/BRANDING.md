# Brand decision

* **Name:** رقيم — **Raqim** (approved by the owner on 2026-11-19), replacing the
  working name Katib/كاتب (collision with the existing "Kateb" dictation app by RDI).
* **Meaning:** الرقيم — the inscribed tablet / written record (Qur'an 18:9).
* **Tagline:** رقيم — محاضر الاجتماعات الذكية · Raqim — AI Meeting Minutes.
* **Rename plan (after the v1 build finishes):** user-visible app name on
  Android/iOS/Windows, window title, strings, README and docs → Raqim/رقيم;
  application id / bundle id → `app.raqim.raqim`; Dart package `katib` → `raqim`.
  The GitHub repository can be renamed by the owner (Settings → Rename);
  GitHub redirects the old URL.
* **Before launch:** formal trademark search (KSA, UAE, Egypt), domain
  (raqim.ai / raqim.app) and store-name availability.
